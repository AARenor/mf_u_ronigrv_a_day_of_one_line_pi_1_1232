# make.fun entry: u-ronigrv-a-day-of-one-line-pitches-12cd9bb3

This repository holds a tiny program that writes one short text for make.fun's bounty `u-ronigrv-a-day-of-one-line-pitches-12cd9bb3`. The text lives in `main.py` as a single string constant; the program writes its UTF-8 bytes with no trailing newline into the folder named by `MAKEFUN_OUTPUT_DIR` (falling back to `OUTPUT_DIR`, then `/output`), creating the folder if needed, and prints the character count to stderr.
